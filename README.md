# Project presentation - `cpp_04`

## **Description**

This project introduces **polymorphism** in C++ and focuses on understanding **virtual functions**, **abstract classes**, and **interfaces**.

Through these exercises, the goal is to learn how dynamic binding works, how to use base class pointers correctly, and why virtual destructors are essential when working with inheritance.

This module emphasizes proper object-oriented design and prepares the ground for more advanced C++ concepts.

## Exercices Overview

### ex00. Polymorphism

Introduction to polymorphism:

- Virtual functions
- Base class pointers to derived objects
- Dynamic dispatch
- Understanding the difference between virtual and non-virtual functions

### ex01. I don’t want to set the world on fire

Deepening polymorphism concepts:

- Proper use of virtual destructors
- Preventing memory leaks in inheritance hierarchies
- Understanding object destruction order
- Reinforcing correct polymorphic behavior

### ex02. Abstract class

Introduction to abstract classes:

- Pure virtual functions
- Abstract base classes
- Enforcing interfaces through inheritance
- Preventing instantiation of base classes

### ex03. Interface & recap

Interface-like design in C++:

- Using abstract classes as interfaces
- Combining multiple abstractions
- Strengthening object-oriented design
- Full recap of polymorphism concepts

# Using `cpp_04`

## How to use `cpp_04`

_Note : this repository contains only the `cpp_04` module. It is part of the global [cpp_modules](https://github.com/bibickette/cpp_modules) repository, which regroups all C++ modules._

1. Clone `cpp_04` in a folder first : `git clone https://github.com/bibickette/cpp_04.git`
2. Move into the repository : `cd cpp_04`
3. Compile the module : `make`; this will compile all exercises contained in the module
4. You can now move into each exercices and run the corresponding executable
